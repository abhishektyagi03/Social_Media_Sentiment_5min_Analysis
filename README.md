# Social Media Sentiment Analysis – AI Trends 2026

## 📌 Project Overview

This project explores social media data related to AI trends in 2026 using Python and the `ydata-profiling` library. It focuses on understanding dataset structure, identifying data quality issues, and generating an automated Exploratory Data Analysis (EDA) report.

## 🎯 Objectives

- Analyze social media data related to AI trends.
- Understand dataset structure and statistical summaries.
- Identify missing values, duplicate records, and potential data quality issues.
- Explore distributions, correlations, and patterns in the dataset.
- Generate an interactive HTML report using `ydata-profiling`.

## 🛠️ Technologies Used

- **Python** – Data analysis and processing
- **Pandas** – Data manipulation
- **YData Profiling** – Automated EDA and data quality reporting
- **Jupyter Notebook** – Interactive analysis

## ⚙️ Project Workflow

1. Import the required Python libraries.
2. Load the social media dataset.
3. Inspect and understand the dataset.
4. Generate a profiling report using `ydata-profiling`.
5. Review missing values, distributions, correlations, and other data quality indicators.
6. Export the report as an HTML file.

## 📦 Installation

Install the required libraries:

```bash
pip install pandas ydata-profiling jupyter
```

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/abhishektyagi03/Social_Media_Sentiment_Analysis_AI_Trends_2026.git
```

2. Open the project folder and launch Jupyter Notebook.
3. Open the project notebook.
4. Run the cells to load the dataset and generate the profiling report.
5. Open the generated HTML report in your browser.
